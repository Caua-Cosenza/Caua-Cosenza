## 📌 Projeto em destaque

### 💈 Sistema de Agendamento — Barbearia

Sistema completo de agendamento online, **em produção desde 26/05/2026**, atendendo uma barbearia real com cerca de **300 clientes/mês**.

Antes do sistema, o barbeiro gerenciava tudo manualmente pelo WhatsApp. O cliente (Jhonatan) relatou que o resultado **superou as expectativas** tanto em funcionalidade quanto na interface.

**O que aprendi construindo esse projeto:**
- Arquitetura de API REST com autenticação segura (JWT em HttpOnly cookies)
- Criptografia de dados sensíveis (AES-256-CBC)
- Deploy em Railway (backend + banco + cache) e Cloudflare Pages (frontend)
- Rate limiting em múltiplas camadas
- ORM com Prisma e migrations de banco de dados
